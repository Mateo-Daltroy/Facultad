## Intro

> [!note] Cloud
> Amazon inventa el concepto de cloud para poder manejar los recursos de manera Escalable, y mas 
> importante, Elastica. De esta manera se minimizan los recursos ociosos

> [!example] Cloud vs Utility Computing
> Utility computing es concepto de computo como modelo de servicio.
> Cloud computing es mas que Utility Computing, es un paradigma de computo distribuido que se sostiene
> sobre la virtualizacion, utilizando una infrastructura fisica sobre la cual el consumidor se puede 
> abstraer sobre la ubicacion y organizacion real.


## Modelos de Servicio
Los principales modelos de servicio son Software como Servicio (Saas), Plataforma como Servicio (PaaS), Infraestructura como Servicio (IaaS)


## Modelos de Despliegue
- Cloud Publico: Todo lo que esta por fuera de nuestra LAN
- Cloud Privado: Todo lo que esta dentro de nuestra LAN
- Cloud Hibrido: Hostear ciertas partes del sistema dentro de clouds publicas mientras que mantenemos las partes sensibles dentro de una nube privada

? Un cloud privado que responde requests del internet, deja de ser privado?
- OpenNebula es un proyecto opensource para manejar cloud privado
